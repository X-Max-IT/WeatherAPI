# React + Vite

A simple responsive weather widget built with React.

The project was created as a practice project to work with React state, effects, API requests, and responsive SCSS styling.

## Features

- Search weather by city
- Automatic weather detection using geolocation
- Current temperature
- Weather condition and icon
- Humidity
- Wind speed
- Dynamic background depending on weather conditions
- Loading and error states
- Responsive design

## Technologies

- React
- JavaScript
- SCSS
- Vite
- WeatherAPI

## Instructions for local launch
The project is built using the modern **Vite** bundler. To run it, you will need Node.js and the npm package manager installed.
1. Clone the repository to your computer.
2. Navigate to the project folder.
3. Install the dependencies: npm install.
4. Start the dev server: npm run dev.
5. Open the address from the terminal in your browser (localhost).
